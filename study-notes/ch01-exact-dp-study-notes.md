## §1.1 Deterministic Dynamic Programming（确定性动态规划）

### 问题框架

所有 DP 问题共享一个骨架：**离散时间** → 每步选控制 $u_k$ → 系统进入下一状态 → 累加代价。确定性版本里，$x_{k+1}$ 没有随机性，给定 $(x_k,u_k)$ 则下一状态唯一。

---

### §1.1.1 Deterministic Problems（问题表述）

#### 主要内容

1. **动力学**（式 1.1）  
   $$

   x_{k+1} = f_k(x_k, u_k), \quad k=0,\ldots,N-1.
   
$$
2. **约束**：$u_k \in U_k(x_k)$——允许控制可以依赖当前状态（例如不能超速、不能走进墙）。  
3. **可加总代价**（式 1.2）  
   $$

   J(x_0; u_0,\ldots,u_{N-1})
   = g_N(x_N) + \sum_{k=0}^{N-1} g_k(x_k, u_k).
   
$$
4. **最优值函数** $J^*(x_0) = \min J(\cdot)$（全书用 `min` 表示 inf，即使最优控制未必达到）。  
5. **两条典型路线**  
   - **有限状态图**：节点 = 状态，弧 = 决策，权 = 阶段代价 → **最短路径**。  
   - **连续状态**：向量 $x_k \in \mathbb{R}^n$，常配合 LQ 结构（例 1.1.2 多段炉温）。

#### 核心公式

| 对象 | 公式 / 含义 |
|------|-------------|
| 系统 | $x_{k+1}=f_k(x_k,u_k)$ (1.1) |
| 总代价 | $J = g_N(x_N)+\sum_{k=0}^{N-1}g_k(x_k,u_k)$ (1.2) |
| 线性二次例 | $x_{k+1}=(1-a)x_k+a u_k$，代价含 $\sum u_k^2 + r(x_N-T)^2$ |

#### 建模要点：从应用问题到 $(f_k,g_k,U_k)$

- **控制变量**：每步需决策的量对应 $u_k$。  
- **状态变量**：影响未来代价且控制器在时刻 $k$ 可用的信息，应纳入 $x_k$。  
- **例 1.1.1（调度）**：状态为已完成工序集合；控制为下一工序；弧权为 setup 代价。  
- **组合优化作为控制**：同一 Bellman 反向递推可用于组合问题；状态规模可能指数级。

#### 要点

- 状态空间、控制空间**可以随 $k$ 变**——这比“固定网格 MDP”更一般。  
- 确定性问题里，优化对象可以是**开环序列** $\{u_k\}$，因为未来状态由当前计划完全决定。

#### 注意点

- 连续问题还可交给非线性规划 / 二次规划；DP 是其中之一，不是唯一工具。  
- LQ **无约束**时后面有解析解（§1.3.7）；有盒约束时要另选方法或验证无约束解是否可行。

---

### §1.1.2 The Dynamic Programming Algorithm（DP 算法）

#### 主要内容

**最优性原理（Principle of Optimality）**：若 $\{u_0^*,\ldots,u_{N-1}^*\}$ 最优，则从最优轨迹上任意时刻 $k$ 的状态 $x_k^*$ 出发，**尾部控制** $\{u_k^*,\ldots,u_{N-1}^*\}$ 对该尾部子问题仍最优。  
**最优性原理的直观表述**：若全程最优，则任意后缀子问题在相应初态上仍最优（图 1.1.5 最短路类比）。

**反向递推**（算余值）：

- 终端：$J_N^*(x_N) = g_N(x_N)$ (1.3)  
- 对 $k=N-1,\ldots,0$：  
  $$

  J_k^*(x_k) = \min_{u_k \in U_k(x_k)}
  \Big[ g_k(x_k,u_k) + J_{k+1}^*\big(f_k(x_k,u_k)\big) \Big] \tag{1.4}
  
$$
- 含义：$J_k^*(x_k)$ 是从 $(k,x_k)$ 到终点、最优的 **cost-to-go** (1.5)–(1.6)。

**正向构造最优控制**（在已知全部 $J_k^*$ 后）：

$$

u_k^* \in \arg\min_{u_k} \big[ g_k(x_k^*,u_k) + J_{k+1}^*(f_k(x_k^*,u_k)) \big], \quad
x_{k+1}^* = f_k(x_k^*,u_k^*) \tag{1.7–1.8}

$$

**例 1.1.1 续**：图 1.1.6 自最短尾部子问题逐层反向填 $J_k^*$；最优总代价 10，控制序列为 CABD。手算可验证 (1.4) 的归纳结构。

#### 核心公式

| 步骤 | 公式 |
|------|------|
| 终端 | $J_N^*=g_N$ (1.3) |
| Bellman | (1.4) |
| 余值含义 | $J_k^*$ = 从 $k$ 起 $(N-k)$ 段最优总代价 (1.5)–(1.6) |
| 正向取控 | (1.7)–(1.8) |

#### 要点

- **计算顺序**：对每个 $k$，(1.4) 要对**所有** $x_k$ 算完，再进入 $k-1$。  
- **输出两样东西**：最优值 $J_0^*(x_0)$ 与（通过 1.7–1.8）**反馈规则**——每个状态该选什么 $u$。  
- 证明核心：**对 $k$ 归纳**——从 $J_N^*=g_N$ 出发，用 (1.4) 把“尾部最优”一层层拼起来。

#### 注意点

- $J_k^*$ 可能取 $-\infty$（数学上），归纳仍成立——实际建模时通常避免无下界代价。  
- 若只对**一个**初态 $x_0$ 感兴趣，理论上仍常做全状态反向（除非有结构可剪枝）；**维度灾难**由此而来——第 2 章起的近似正是为缓解这一点。

### §1.1.3 Approximation in Value Space & Q-Factors（值空间近似与 Q 因子）

#### 主要内容

**计算动机**：精确计算各 $(k,x_k)$ 上的 $J_k^*$ 在状态空间大时不可行；以 $\tilde J_k$ 替代 $J_k^*$ 并保留 Bellman **结构**作正向决策（(1.9)–(1.10)），为全书 RL/近似 DP 的主线。

**一步前瞻（suboptimal）**：

$$

\tilde u_k \in \arg\min_{u_k} \Big[ g_k(\tilde x_k,u_k) + \tilde J_{k+1}\big(f_k(\tilde x_k,u_k)\big) \Big], \quad
\tilde x_{k+1}=f_k(\tilde x_k,\tilde u_k) \tag{1.9–1.10}

$$

**Q 因子**（确定性，式 1.11）：

$$

Q_k^*(x_k,u_k) = g_k(x_k,u_k) + J_{k+1}^*\big(f_k(x_k,u_k)\big).

$$

则 $J_k^*(x_k)=\min_{u_k} Q_k^*(x_k,u_k)$，且 Bellman 可**只写在 Q 上**（与 Watkins Q-learning 符号一脉）。  
近似时 $\tilde Q_k = g_k + \tilde J_{k+1}$，选控 $\tilde u_k = \arg\min_u \tilde Q_k(\tilde x_k,u)$——**不必显式存 $\tilde J_k$**，利于函数逼近（第 3 章）。

#### 要点

- 精确 DP：通常**先反向**得 $J_k^*$，再正向。  
- 近似 DP：常**离线/预计算** $\tilde J_k$ 或 $\tilde Q_k$，**在线**只做一步 minimization——计算预算从“全状态 Bellman”变成“当前状态上一行 argmin”。  
- Q 形式把“选控”与“余值”拆开：控制比较只依赖 $Q$ 差，对近似误差有时更友好（第 2、3 章会再提 **advantage**）。

#### 注意点

- $\tilde J_k$ 不必接近 $J_k^*$ 才能有用——关键是在**将要访问的状态**上，$g+\tilde J_{k+1}$ 的**排序**对控制选择正确（第 2 章会细讲）。  
- 1.9–1.10 是**开环**地沿 $\tilde u$ 滚动；若 $\tilde J$ 差，误差会累积——这也是 rollout/MPC 等方法要讨论的原因。

## §1.2 Stochastic Dynamic Programming（随机动态规划）

### 问题框架

动力学为
$$

x_{k+1} = f_k(x_k, u_k, w_k), \quad w_k \sim P_k(\cdot \mid x_k, u_k),

$$
阶段代价可为 $g_k(x_k,u_k,w_k)$。**优化变量**为由反馈映射 $\mu_k$ 构成的策略 $\pi=\{\mu_0,\ldots,\mu_{N-1}\}$（$u_k=\mu_k(x_k)$），而非固定开环序列：在随机扰动下，控制器需根据**已实现状态**调整决策，开环序列在期望意义下通常次优。

### 主要内容

- **期望总代价**（给定 $x_0$ 与策略 $\pi$）  
  $$

  J_\pi(x_0) = \mathbb{E}\Big[ g_N(x_N) + \sum_{k=0}^{N-1} g_k\big(x_k,\mu_k(x_k),w_k\big) \Big].
  
$$
- **最优** $J^*(x_0)=\min_{\pi\in\Pi} J_\pi(x_0)$。  
- **随机 Bellman**（式 1.12–1.13）：  
  $$

  J_N^*(x_N)=g_N(x_N),
  
$$
  $$

  J_k^*(x_k) = \min_{u_k\in U_k(x_k)}
  \mathbb{E}_{w_k}\Big[ g_k(x_k,u_k,w_k) + J_{k+1}^*\big(f_k(x_k,u_k,w_k)\big) \Big]. \tag{1.13}
  
$$
  若每步 minimizer 为 $\mu_k^*(x_k)$，则 $\pi^*=\{\mu_k^*\}$ 最优。  
- **随机 Q 因子**：(1.13) 右侧被最小化的量；Q 的 Bellman 形式期望可用**采样**近似——第 4–5 章 simulation-based 算法的数学支点。

### 与 §1.1 的对照表

| 维度 | 确定性 §1.1 | 随机 §1.2 |
|------|-------------|-----------|
| 优化对象 | 控制序列 $\{u_k\}$ | 策略 $\mu_k(x_k)$ |
| Bellman | 无期望 | 对 $w_k$ 取期望 |
| 计算 | 已可能很大 | 更大（每层多一层期望） |
| 近似 | $\tilde J_k$ 一步前瞻 | 同样结构 + 常需 MC 估期望 |

### 要点

- **信息结构**：反馈策略 $u_k=\mu_k(x_k)$ 利用到达状态的信息；开环序列在随机问题中一般严格次优。  
- **仿真**：评估 $J_\pi$ 或 Bellman 右端时，常需对 $w_k$ 轨迹采样——“模型-free”在后续章节会与“是否用采样算期望”挂钩。

### 注意点

- (1.13) 中期望良定义、有限性在一般测度论下有技术条件；**有限 $w_k$** 时就是有限和，工程上常直接算。详见 [Ber17] Ch.1、[BeS78]。  
- 随机 DP 同样遭遇维度灾难 → **近似余值 + 采样** 是 RL 标准路线。

## §1.3 Examples, Variations, and Simplifications（例题、变体与化简）

### §1.3 开篇：状态与控制的形式化步骤

#### 主要内容

建模通常分两步进行：

**(a) 定控制与时间**  
- 控制 $u_k$ 是什么？何时做决策？  
- **确定性**可把多步决策“ lump 成一步”（如 $(u_0,u_1)$ 一起选）。  
- **随机**里决策时刻通常与**可用信息**绑定，不能随意合并。

**(b) 选状态 $x_k$**  
- 准则：$x_k$ 应包含时刻 $k$ **已知且对选 $u_k$ 有用**的一切——过去若与 $x_k$ 无关则不应再影响最优控（**Markov / 分离过去与未来**）。  
- 常存在多种合法状态；应倾向**维数更低**的表示（例：$x_k$ 合法则一般不必用 $(x_{k-1},x_k)$）。  
- **部分信息**：可用全历史 $I_k$，或 **belief state** $P(x_k\mid I_k)$——后者是充分统计，但可能无穷维；$I_k$ 有限维却可能冗余。见 §1.3.6。

#### 要点

- 建模=艺术：**状态选错**不会改最优代价的存在性，但会让 DP **算不动**或策略不可实现。  
- 后文各例都在练“同一物理问题，不同状态编码”。

---

### §1.3.1 Deterministic Shortest Path Problems（确定性最短路径）

#### 主要内容

- 图节点 $\{1,\ldots,N,t\}$，弧 $(i,j)$ 代价 $a_{ij}$，目标：各节点到 $t$ 的最短路径。  
- 假设：**无负长度环**（否则可无限绕圈降代价）。  
- 化为 **$N$ 段 DP**：阶段 $k=0,\ldots,N-1$ 的状态为当前节点；控制 = 选 outgoing 弧；$N$ 步内允许自环 $a_{ii}=0$ 表“少走几步”。  
- **余值含义**：$J_k^*(i)$ = 从 $i$ 出发、**恰用 $N-k$ 步**到 $t$ 的最优代价。  
- **Bellman（Bellman–Ford 形）**  
  $$

  J_k^*(i) = \min_{j:(i,j)\text{ 弧}} \big[ a_{ij} + J_{k+1}^*(j) \big], \quad
  J_{N-1}^*(i)=a_{it}.
  
$$
- **提前终止**：若某 $k$ 起 $J_k^*(i)=J_{k+1}^*(i)$ 对所有 $i$ 成立，则已得“真实最短距离”（不再依赖剩余步数）。

#### 要点

- 这是理解 (1.4) 的**最好手绘练习**之一（图 1.3.1）。  
- 最短路径与 §1.1.1 有限状态控制是**同一数学对象**。

#### 注意点

- 强制 $N$ 步 + 零自环是技巧；真实最短路径长度 $\le N$ 时在 $k$ 处“冻结”余值。

---

### §1.3.2 Discrete Deterministic Optimization（离散组合优化）

#### 主要内容

- **TSP（例 1.3.1）**：状态 = 已访问城市的序列（长度 $k$），控制 = 下一个城市；终端连回起点；**状态数随 $N$ 指数增长** → 精确 DP 不可行，但 formulation 为 **rollout / 近似 DP** 铺路（第 2、4 章）。  
- **一般离散优化** $\min_{u\in U} G(u)$，$u=(u_1,\ldots,u_N)$：  
  - 阶段 $k$ 的状态 = 前缀 $(u_1,\ldots,u_k)$；  
  - 从 $(u_1,\ldots,u_k)$ 只能扩展到可行 $u_{k+1}\in U_{k+1}(\cdot)$；  
  - 终端代价 $G(u)$（图 1.3.3）。  
- **反向** (1.14)：  
  $$

  J_k^*(u_1,\ldots,u_k) = \min_{u_{k+1}} J_{k+1}^*(u_1,\ldots,u_k,u_{k+1}),
  \quad J_N^*=G.
  
$$
- **正向** (1.15) 构造 $u_1^*,\ldots,u_N^*$。  
- **Rollout 预告**：用启发式 $\tilde J_{k+1}$ 替换 (1.15) 中的 $J_{k+1}^*$——固定前缀，用启发式补全后面，是强力的组合优化近似。

#### 要点

- “DP 解组合优化”在**建模**上总是对的，在**计算**上常常爆炸——本书立场：用 DP **结构** + **近似**（rollout、MCTS 等）。  
- 也可接 A*、label correcting、branch-and-bound（[Ber17] Ch.2）。

#### 注意点

- TSP 图 1.3.2 展示两条最优 tour（对称）；forward pass (1.7) 可任取其一。

### §1.3.3 Problems with a Terminal State（终端状态）

#### 主要内容

- **终端状态 $t$**：吸收、零代价：$g_k(t,\cdot)=0$，$f_k(t,\cdot)=t$。  
- 可在 $k<N$ 提前进入 $t$；进入 $t$ 后阶段代价为零且状态不再变化。  
- **四皇后（例 1.3.2）**：序贯放后；对称性剪枝（顶行只试前两格）；死胡同连 artificial $t$，弧权 1；可行布局弧权 0 → **最小代价路径 = 合法解**。  
- 大图 N 皇后：状态空间仍巨大 → 精确 DP 不现实，但 formulation 清晰。

#### 要点

- 许多“找可行解”的 puzzles = **最短路径到 $t$**，代价设计编码“失败/成功”。  
- 若最优策略在未知步数内必停，可设 $N$ 上界化为有限时域；否则需无限时域（第 4 章 SSP）。

#### 注意点

- 与 §1.3.2“恰好 $N$ 步到终端”对比：这里强调**提前吸收**。

---

### §1.3.4 Forecasts（预测信息）

#### 主要内容

- 控制器在 $k$ 收到**预测** $y_k$，使对 $w_k$ 的分布从“模糊”变为“若干模型之一”。  
- 典型设定：预测 $i\in\{1,\ldots,m\}$ 先验概率 $p_i$；若预测为 $i$，则 $w_k\sim P_i$。  
- **增广状态** $\tilde x_k=(x_k,y_k)$，预测方程 $y_{k+1}=\xi_k$（随机取 $i$ 概率 $p_i$），与系统方程并列。  
- Bellman (1.16) 在 $(x_k,y_k)$ 上写；控制依赖**当前物理状态 + 当前预测**。  
- 扩展：预测可受控、可覆盖多步扰动——代价是状态维数上升。

#### 要点

- 纳入更多信息一般**扩大状态空间**；需在建模精度与计算复杂度之间权衡。  
- 与 §1.3.5 结合：预测 $y_k$ 常是**不可控状态分量**，可用 (1.18) 化简。

#### 注意点

- 实现 (1.16) 时，对 $w_k$ 的期望在**已知预测 $y_k$** 的条件下取。

### §1.3.5 Problems with Uncontrollable State Components（不可控状态分量）

#### 主要内容

- 状态 $(x_k,y_k)$：$x_k$ 受 $u_k,w_k$ 影响；$y_k$ 只按 $P(y_{k+1}\mid x_k,\ldots)$ 演化，**控制不能直接改 $y_k$**（但可间接通过 $x_k$）。  
- **停车（例 1.3.3）**：沿 $0,\ldots,N-1$ 车位，车库 $N$ 代价 $C$；位 $k$ 空闲概率 $p(k)$，观测到空闲才决定停或走。  
- 先在完整 $(k,F)/(k,\bar F)$ 上写 DP，再化简为**标量**  
  $$

  \hat J_k = p(k) J_k^*(F) + (1-p(k)) J_k^*(\bar F),
  
$$
  表示“到达 $k$ 尚未知空满前的期望余值”。  
- 反向：  
  $$

  \hat J_{N-1} = p(N-1)\min\{c(N-1),C\} + (1-p(N-1))C,
  
$$
  $$

  \hat J_k = p(k)\min\{c(k),\hat J_{k+1}\} + (1-p(k))\hat J_{k+1}.
  
$$
- **策略**：在 $k$ 若空闲且 $c(k)\le \hat J_{k+1}$ 则停。单调 $c(k)$ 时可有**阈值策略**（图 1.3.6：开到 165 再“见空就停”）。

**一般公式 (1.18)**：对 $x_k$  alone 递推  
$$

\hat J_k(x_k) = \mathbb{E}_{y_k}\Big[ \min_{u_k} \mathbb{E}_{w_k}\big[ g_k + \hat J_{k+1}(f_k(\cdot)) \big] \Big],

$$
状态空间从 $n\times m$ 降到 $n$——**最优控仍可能是 $(x_k,y_k)$ 的函数**。

#### 要点

- “观测在控前/扰动在控后”区分 $y_k$ 与 $w_k$。  
- 排队等**到达事件**常作不可控分量；Tetris 下落块形状 $y$ 同理（§1.3.5 末例 1.3.4）。

#### 注意点

- 化简算法算的是 $\hat J_k(x_k)$，实现策略时仍要记当前观测到的 $y_k$。

### §1.3.6 Partial State Information and Belief States（部分状态信息与信念状态）

#### 主要内容

- 假设改为：控制器**不完美**观测 $x_k$，而只有噪声测量或部分分量。  
- 概念上可化为**完美信息 DP**，状态换成 **belief state** $p_k = P(x_k\mid I_k)$（图 1.3.8）。  
- **寻宝（例 1.3.5）**：$x_k\in\{\text{有宝},\text{无宝}\}$；$p_k=P(\text{有宝})$；搜索代价 $C$，发现概率 $\beta$，价值 $V$。Bayes 更新 (1.19)，在 $p_k$ 上 DP (1.20)。  
- **结论**：搜索当且仅当 $p_k \beta V \ge C$——**短视（myopic）最优**，只比较“下一步期望收益 vs 成本”。  
- **信念维数灾难**：$x_k$ 取 $n$ 值 → belief 在 $(n-1)$-单纯形上；连续 belief 需离散化。  
- **双向停车（例 1.3.6）**：belief 为各车位空闲概率向量，随观测更新；精确 DP **可写不可算** → 近似（后章）。  
- **例 1.3.7（充分统计量）**：车位状态不变时，belief 可压缩为“当前位置空满 + 目前最佳已知空位索引”——**维数大减**，DP 可在 $i_k\in\{0,\ldots,k,-1\}$ 上执行。

#### 要点

- 部分信息 ≠ 新算法族，而是**状态升维**（到 belief 或历史）。  
- **充分统计量**：把历史压成低维量且不减最优性——建模时最值得找的“捷径”。

#### 注意点

- 例 1.3.5 的 myopic 最优**不**可推广到一般 POMDP。  
- 无限时域、不停车可一直移动 → 例 1.3.6 常作无限时域或加步数上限（脚注）。

### §1.3.7 Linear Quadratic Optimal Control（线性二次控制）

#### 主要内容

- **标量 LQ（例 1.1.2，$N=2$ 手算）**：  
  - $J_2^*(x_2)=r(x_2-T)^2$。  
  - 对 $u_1$ 二次 minimization → 仿射最优策略 $\mu_1^*(x_1)$ (1.22)，余值仍为 $x_1$ 的二次 (1.21)。  
  - 再对 $u_0$ 重复 → $\mu_0^*(x_0)$ (1.23)，$J_0^*(x_0)$ 闭式。  
- **一般结论**：线性系统 + 二次代价 + 无约束 → **最优策略仿射、余值二次**，任意 $N$ 闭式（Riccati，见 [Ber17] §3.1）。  
- **随机 LQ**：$x_{k+1}=(1-a)x_k+a u_k + w_k$，$\mathbb{E}w_k=0$。期望里出现 $\mathbb{E}w_k$ 与 $\mathbb{E}w_k^2$：**策略与确定性相同**，余值多常数项 → **Certainty Equivalence（确定性等价）**。  
- 非 LQ 问题可用“确定性等价”作**近似**（把随机换成典型值，再精确 DP，§2.3.2）。

#### 核心公式（节选）

| 对象 | 结果 |
|------|------|
| $\mu_1^*(x_1)$ | $\dfrac{ra(T-(1-a)x_1)}{1+ra^2}$ (1.22) |
| $J_1^*(x_1)$ | $\dfrac{r((1-a)x_1-T)^2}{1+ra^2}$ |
| 随机 | 最优 $\mu_k^*$ 不变，$J_k^*$ 加噪声方差常数 |

#### 要点

- LQ 是少数“Bellman 可手算到底”的模板，也是**近似 DP 初值 / 局部线性化**的来源。  
- DP 同时给出**全状态反馈** $\mu_k^*(x_k)$——不是只算开环 $u_0,u_1$。

#### 注意点

- 无约束解可能 $u_k<0$（加热为负）——工程上需 clip 或改建模。  
- Certainty equivalence 依赖 LQ 特殊结构；一般随机问题不成立。

## §1.4 Reinforcement Learning and Optimal Control — Terminology

### 主要内容

最优控制/DP 与人工智能/RL 在 80–90 年代交汇，但**术语与符号**仍易混淆。本书采用 **cost / minimization / $J$ / $g$ / $f$ / $x$ / $u$**（Bellman–Pontryagin 传统）；RL 文献常用 reward maximization 与 agent–environment 叙事。

**对照表（节选，原文 (a)–(v)）**：

| RL / AI | 最优控制 / 本书 |
|---------|------------------|
| Agent | 决策者 / controller |
| Action | 控制 $u$ |
| Environment | 系统 |
| Reward | **负的**阶段代价 $-g$ |
| State value | **负的** cost-to-go $-J$ |
| Value / state-value function | Cost(-to-go) function $J$ |
| Maximizing value | Minimizing cost |
| Action value / state-action value | Q-factor $Q(x,u)$ |
| Planning | 有模型解 DP |
| Learning | 无模型（或采样）解 DP |
| Self-learning / self-play | 策略迭代（PI） |
| Deep RL | 深度网络值/策近似 |
| Prediction | 策略评估 |
| Generalized policy iteration | 乐观 PI |
| State abstraction | 聚合 (aggregation) |
| Learning a model | 系统辨识 |
| Episodic task / episode | 有限步轨迹 |
| Continuing task | 无限步轨迹 |
| Backup | 单态应用 DP 算子 |
| Sweep | 全状态 backup |
| Greedy w.r.t. $J$ | Bellman 最小化策略 |
| Afterstate | Post-decision state |

**符号（原文 Summary）**：

| 符号 | 含义 |
|------|------|
| $x,u$ | 连续状态、控制 |
| $i,p_{ij}(u)$ | 离散状态、转移概率 |
| $J,g,f$ | 余值、阶段代价、系统函数 |

### 要点

- 读 RL 文献时将 “maximize value” 转为 “minimize cost” 即可对接本书。  
- **Policy iteration** 等词在两传统中算法细节可能略有差异——以 Bellman 结构为准对齐。

### 注意点

- 本书刻意简短；精确 DP 见 [Ber12]、[Ber17]；**维度灾难**与**建模灾难**（用模拟器替代解析模型）是近似 DP/RL 的核心动机（§1.4 开篇）。

## 本章小结
